# ShopManager
A very simple 2D Android idle/tycoon game, inspired by supermarket simulator games. Buy stock, set your prices, leave the game running, and watch customers buy items. Earn money, level up, and unlock more products.

## Game concept
Buy stock: spend money to restock products.
Set prices: choose what to charge for each product.
Idle sales: items get bought over time, even while you are away.
Level up: progress unlocks new item options.

The game is mostly menus, buttons, and numbers rather than sprites and physics, so it uses standard Android UI instead of a game engine.

## Tech choices

Language	Java
IDE	Android Studio
UI	Standard Android views (XML layouts)
Saving	SharedPreferences
